v20 — ズーム誤判定の根本原因修正

確認した原因:
旧CSSでは
  .atlas.zoom .layer, .atlas.zoom .map { transform: ... }
となっており、人体画像だけでなく「透明なタップ判定マップ」までズーム・移動していた。

そのため一度腹部などをズームした後は、画面上の頭/首/胸部の位置と
透明ボタンの位置が一致しなくなり、別部位（特に腹部）が選択されていた。

修正:
1. transform対象を .layer（画像）だけに限定
2. .map は常に transform:none
3. openRoute時にも map transform:none を防御的に適用
4. 骨盤 57–66% / 下肢 66–99% と境界を完全分離
5. 骨盤横幅も30%へ狭め、中央骨盤・股関節レベルに限定
6. 下肢は66%から開始し、大腿を下肢側へ移管

検証:
- 旧「画像＋map同時transform」CSSが残っていないことをassert確認
- 骨盤/下肢境界が重複していないことをassert確認
- JavaScript node --check: OK

開発確認用:
URL末尾に ?debug=1 を付けると透明タップ領域が可視化される。
通常表示では一切見えない。
