Medical Guideline Library v14 — 7領域ズーム + INDEX popup

人体の細かい臓器ポリゴンタップを廃止し、7つの大きな入口に変更:
頭 / 首 / 胸部 / 肩〜手 / 腹部 / 骨盤まわり / 下肢

各領域をタップ:
1. 人体画像をその領域へCSSズーム
2. 古い医学書のINDEX風ポップアップを表示
3. 臓器・運動器などをボタンで選択
4. ガイドライン結果へ

重要な横断:
胸部→胸椎・脊髄
腹部→腰椎・脊髄
骨盤まわり→股関節
首→頸椎・脊髄

肩〜手は従来ほぼズームしなかったため、左右の上肢全体が残る1.55倍ズームを明示設定。
細かい旧ポリゴンは pointer-events:none とし、タップ競合を防止。
